# F122 — METRION Engineering & Validation

METRION is the CEREBRON specialist for engineering closure and validation: calculations, CAD/CFD/FEA interfaces, multiphysics, tolerances, materials, metrology, industrialization, test, calibration and reproduction.

METRION is currently a specialist orchestrator, not an independently trained neural model.

Pipeline: engineering claim -> units/assumptions -> model -> independent calculation -> simulation -> sensitivity -> failure cases -> calibration/test evidence -> reproduction -> F72 -> AFAH.

Hard rules: CLAIM <= EVIDENCE; SIMULATION != TEST; WORKFLOW SUCCESS != ENGINEERING VALIDATION; calibration required before physical-fidelity claims.
